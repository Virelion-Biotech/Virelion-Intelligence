# Evidence policy

## Evidence level

- `E0`: unverified
- `E1`: secondary source
- `E2`: primary publication
- `E3`: primary publication plus public code or data
- `E4`: independent reproduction
- `E5`: replicated across independent studies

## Evidence depth

- `M0`: metadata only
- `M1`: abstract
- `M2`: full-text narrative
- `M3`: full text plus figures/tables
- `M4`: full text plus linked code/data

## Provenance rule

Every substantive claim must link to a source and an evidence object. Supporting text should be preserved whenever available, together with section/figure/table location. Author interpretation must remain distinguishable from the system's own inference.

## Confidence rule

Extraction confidence measures confidence that the system represented the source correctly. It is not a proxy for biological truth or replication strength.
